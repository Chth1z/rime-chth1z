# [Bug] `symbols_v.yaml` 含 `/you` 残留 `'/ 友'`、`/weishengdongwu` 拼写错误及 `/dn` `/fs` 遗漏

## 环境与版本
- **上游版本**：`gaboolic/rime-frost@c982966`（已确认最新 `master` 仍可复现；其中 `/you` 与 `/weishengdongwu` 为白霜独有，`/dn` 与 `/fs` 承自雾凇）
- **客户端与引擎**：Weasel `0.17.4` / `librime 1.17.0`
- **影响范围**：使用 `/` 前缀符号表的全部白霜方案

## 实际影响
- **属于哪类问题**：符号表词项错误与触发键拼写错误
- **实际影响说明**：
  1. `symbols_v.yaml:425` 的 `'/you'` 中混入字面量 `'/ 友'`（疑似由 `rime-ice` 原 `'vyou': [→, ➡️, 'V 友']` 批量替换 `v` → `/` 时误伤），用户输入 `/you` 选择右箭头时会弹出无意义的 `'/ 友'`。
  2. `symbols_v.yaml:386` 的野生动物符号组键名误拼为 `'/weishengdongwu'`（实际内容为 `🦉, 🦇, 🐍, 🐢, 🦝, 🦨, ...` 等野生动物，并非微生物），输入 `/yeshengdongwu` 无法命中。
  3. `symbols_v.yaml:15` 的 `'/dn'` 遗漏两个逗号导致 `⌝⌞⌟` 粘连成单个候选；`symbols_v.yaml:69` 的 `'/fs'` 分数表遗漏 `¾`。

## 复现步骤
1. 使用干净的 `gaboolic/rime-frost@c982966` 默认配置部署，在默认全拼 `rime_frost` 下实测：
   - 输入 `/you` → 候选为 `['→[〔全角〕]', '➡️', '/ 友']`
   - 输入 `/yeshengdongwu` → 无候选；改输入 `/weishengdongwu` → 弹出 `['🦉', '🦇', '🐍', '🐢', '🦝', '🦨', ...]`
   - 输入 `/fs` → `⅟, ½, ↉, ⅓, ⅔, ¼, ⅕, ...`，缺少 `¾`
   - 输入 `/dn` → 包含粘连项 `⌝⌞⌟`
2. **预期结果**：`/you` 仅保留箭头符号、`/yeshengdongwu` 可正常触发野生动物列表、`/dn` 拆分 `⌜, ⌝, ⌞, ⌟`、`/fs` 补齐 `¾`。

## 原因位置
- `symbols_v.yaml:15`：`'/dn': [ ..., ⌜, ⌝⌞⌟, ⍑, ... ]`
- `symbols_v.yaml:69`：`'/fs': [ ⅟, ½, ↉, ⅓, ⅔, ¼, ⅕, ... ]`
- `symbols_v.yaml:386`：`'/weishengdongwu': [🦉, 🦇, 🐍, 🐢, ...]`
- `symbols_v.yaml:425`：`'/you': [→, ➡️, '/ 友']`

## 修改建议
```yaml
  '/dn': [ ..., ⌜, ⌝, ⌞, ⌟, ⍑, ... ]
  '/fs': [ ⅟, ½, ↉, ⅓, ⅔, ¼, ¾, ⅕, ⅖, ⅗, ⅘, ⅙, ⅚, ⅐, ⅛, ⅜, ⅝, ⅞, ⅑, ⅒ ]
  '/yeshengdongwu': [🦉, 🦇, 🐍, 🐢, ...]
  '/you': [→, ➡️]
```
